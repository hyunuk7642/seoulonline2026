# 서울온라인학교 2026 운영 성과 — 모션그래픽

성과 보고 덱(「2026서울온라인학교_성과 공유 예시」)의 내용을 32초 모션그래픽으로 옮긴 것입니다.
결과물은 `out/seoul-online-school-2026.mp4` (1920×1080, 60fps, 음악 포함)입니다.

## 구성 (120 BPM, 2초 = 1마디)

| 시간 | 장면 | 덱에서 가져온 내용 |
|---|---|---|
| 0–6초 | 보고서 클로즈업 → 문서 더미 | 학교 개요 문장, 107강좌·168교·1,184명 |
| 6–8초 | 로고 리빌 (ON 스위치) | 서울온라인학교 · 경계 없는 배움, 꿈을 향한 선택 |
| 8–12초 | 시간표 카드 | 주문형(일과 내) · 거점형(방과후·주말) · 계절학기(방학) |
| 12–16초 | 과목 스크롤 + 카운터 | 개설 과목, 1학기 107강좌 |
| 16–20초 | 점 그리드 → 숫자 | 참여 학교 99 → 168교(+70%), 수강생 823 → 1,184명(+44%) |
| 20–24초 | 하이라이트 카드 | 서ON러닝페스타, XR 스튜디오 50실, 국제공동수업 등 8건 |
| 24–28초 | 2027 주문형 | 참여 학교 24 → 46교, 36과목, 106건, 162분반 |
| 28–32초 | 엔드 카드 | 슬로건, 감사합니다 |

## 색

학교 누리집 로고에서 추출한 보라 `#641C84`와 청록 `#05ADA0`을 주색으로 썼습니다.
어두운 배경용 밝은 청록(`#3BDCCB`)과 계절학기 표시용 코랄(`#F2788F`)은 보조색입니다.

## 다시 만들기

```bash
npm install
```

```bash
python3 audio.py
```

```bash
node render.mjs
```

- `src/index.html` — 장면과 타임라인(GSAP). 브라우저에서 열면 실시간으로 재생됩니다.
- `render.mjs` — Playwright로 프레임을 캡처하고 ffmpeg로 인코딩합니다. `--stills 1,2.5`, `--sheet` 옵션으로 확인용 스틸을 뽑을 수 있습니다.
- `audio.py` — 배경 트랙 합성(numpy만 사용, 외부 음원 없음).

수치와 문구는 모두 덱에 있는 값이며, 시간표 화면은 예시입니다.
