# 서울온라인학교 2026 운영 성과 — 모션그래픽

성과 보고 덱(「2026서울온라인학교_성과 공유 예시」)과 영상 시나리오 문서(「서울온라인학교 2026 성과 공유 영상 시나리오」)의 내용을 40초 모션그래픽으로 옮긴 것입니다.
결과물은 `out/seoul-online-school-2026.mp4` (1920×1080, 60fps, 음악 포함)입니다.

## 구성 (120 BPM, 2초 = 1마디)

| 시간 | 장면 | 내용 |
|---|---|---|
| 0–6초 | 보고서 클로즈업 → 문서 더미 | 학교 개요 문장, 107강좌·168교·1,184명 |
| 6–8초 | 로고 리빌 (ON 스위치) | 서울온라인학교 · 한 해의 기록 |
| 8–12초 | 시간표 카드 | 주문형(일과 내) · 거점형(방과후·주말) · 계절학기(방학) |
| 12–16초 | 과목 스크롤 + 카운터 | 개설 과목, 1학기 107강좌 |
| 16–20초 | 점 그리드 → 숫자 | 참여 학교 99 → 168교(+70%), 수강생 823 → 1,184명(+44%), 강좌 61 → 107, 교사 11 → 36명 |
| 20–24초 | 수업의 질 | 1학기 이수율 95.2%(1,199명 중 1,141명), 첨삭·피드백 14,653회(1인당 12.2회) |
| 24–28초 | 하이라이트 카드 | 제2회 서ON러닝페스타, XR 스튜디오 50실, 국제공동수업 1회 → 3차 등 8건 |
| 28–32초 | 2027 주문형 | 2026 참여 24교 → 2027 개설 확정 46교, 36과목·106건·156학급 |
| 32–36초 | 맺음 문장 | 168개 학교 · 1,184명의 학생 · 14,653번의 피드백 (모두 1학기 기준) |
| 36–40초 | 엔드 카드 | 슬로건, 감사합니다 |

## 숫자 기준

- 2025와 2026을 나란히 놓는 지표는 시나리오 문서의 「2025 → 2026 핵심 숫자」 표를 따랐습니다. 2025 값은 회색, 2026 값은 흰색입니다.
- 연간 수강 학생 2,113명은 넣지 않았습니다. 2학기 929명이 공문이 아닌 Teams 집계라서, 맺음 문장은 시나리오 문서가 권한 대로 1학기 값으로 맞췄습니다.
- 이수율 95.2%와 피드백 14,653회는 국회의원 요구자료 108행 합산값으로, 1학기 강좌 수(107)와 한 줄 차이가 있어 담당자 확인이 필요합니다.
- 24교(2026 참여)와 46교(2027 개설 확정)는 기준이 달라 화면에 각각 표기했습니다.
- 예산과 학생·교직원 이름은 넣지 않았습니다. 시간표 화면은 예시입니다.

## 색

학교 누리집 로고에서 추출한 보라 `#641C84`와 청록 `#05ADA0`을 주색으로 썼습니다.
어두운 배경용 밝은 청록(`#3BDCCB`)과 계절학기 표시용 코랄(`#F2788F`)은 보조색입니다.

## 다시 만들기

```bash
npm install
```

```bash
python3 audio.py
```

```bash
node render.mjs
```

- `src/index.html` — 장면과 타임라인(GSAP). 브라우저에서 열면 실시간으로 재생됩니다.
- `render.mjs` — Playwright로 프레임을 캡처하고 ffmpeg로 인코딩합니다. `--stills 1,2.5`, `--sheet` 옵션으로 확인용 스틸을 뽑을 수 있습니다.
- `audio.py` — 배경 트랙 합성(numpy만 사용, 외부 음원 없음).
